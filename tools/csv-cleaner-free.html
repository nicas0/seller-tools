3What counts as a duplicate?

Rows that are identical in every column are always flagged. To also catch rows that share an ID but differ elsewhere (for example, the same order number with a different amount), tick the column(s) that together should be unique.

One row per item? Etsy and Shopify exports put each item of an order on its own row, so one order number can appear several times on purpose. Tick the order column and the item column (SKU, item or product), so separate items aren't flagged.

Fill in order details on item rows (optional)

Only blank cells are filled, only with that same order's own value, and the change log counts every one. Cells that already have a value are never changed.
