Find duplicate rows in Excel without deleting anything

Remove Duplicates deletes rows straight away, and on an order export it deletes real items. Flag the repeats first, look at them, then decide.

Flag repeats with one formula

  1. Find the order number column (for example A) and the item column (SKU or product name, for example E).
  2. In the first empty column, on row 2, type:
    =COUNTIFS($A$2:$A$5000,A2,$E$2:$E$5000,E2)>1
  3. Copy it down. TRUE means another row has the same order and item.
  4. Filter that column for TRUE and compare those rows: if every column matches, it's a real repeat; if the quantity or price differs, check that order by hand.

Matching on the order number alone flags every order with more than one item. That's the usual cause of "duplicate orders" that aren't: see why exports repeat order numbers.
