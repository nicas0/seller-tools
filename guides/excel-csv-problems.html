The file is UTF-8 (normal for exports), but Excel on Windows opens a CSV as UTF-8 only if the file starts with a small marker called a byte-order mark. Without it, accented letters turn into pairs of strange characters.

To open it correctly: in Excel, use Data > From Text/CSV, choose the file, and set File Origin to "65001: Unicode (UTF-8)" before loading. Opening it in Google Sheets also reads it correctly.

ZIP codes and SKUs lose their leading zeros

When Excel opens a CSV directly, it turns 02134 into the number 2134 (and long numbers into 1.23E+15). The file itself is fine; Excel changes it on screen, and saving from Excel makes the change permanent. Import with Data > From Text/CSV and set those columns to Text, or open the file in Google Sheets.
